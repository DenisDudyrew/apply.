# apply.

**Бесплатный локальный помощник для поиска вакансий и откликов на hh.ru.**

Приложение для Windows и macOS: выберите своё резюме, настройте подборку и сопроводительное письмо, проверьте найденные вакансии и запустите отклики. Данные и очередь хранятся на вашем компьютере. Собственный сервер для работы не нужен.

**[Скачать приложение для Windows и Mac →](https://github.com/DenisDudyrew/apply./releases)** · [Исходники](https://github.com/DenisDudyrew/apply.) · [Сообщить об ошибке](https://github.com/DenisDudyrew/apply./issues)

> **Статус: desktop beta 0.1.** Проект создаётся для бесплатной личной помощи и использования друзьями. Это независимый клиент, не официальный продукт hh.ru. Работа авторизации и откликов зависит от изменений сервиса.

## Что умеет

| Возможность | Как работает |
| --- | --- |
| Вход в hh.ru | Телефон или почта и подтверждение кодом в приложении. Регистрировать собственное API-приложение не нужно. |
| Профили резюме | Загрузка своих резюме и отдельные настройки поиска и письма для каждого профиля. |
| Подбор вакансий | Рекомендации hh.ru по выбранному резюме или поиск по ключевым фразам с дополнительным фильтром названий. Поддерживаются разные профессии, не только аналитика. |
| Предварительный просмотр | Подборка вакансий без отправки откликов. |
| Сопроводительные письма | Отдельный шаблон на профиль: с каждым откликом, только когда обязательно или без письма. |
| Настраиваемый максимум | От 1 до 1000 подтверждённых новых отправок за запуск; по умолчанию 1000. |
| Пропуск анкет | Обязательные вопросы и тесты можно пропускать; доступные ручные формы показываются внутри панели. |
| Сохранение очереди | Необработанные карточки можно продолжить после остановки или перезапуска приложения. |
| Журнал и защита от повторов | Учёт пары «резюме + вакансия», причины пропусков и отдельные записи, требующие проверки доставки. |
| Живой прогресс | Счётчики, история, фильтры, текущая вакансия и отсчёт пауз. |

Соответствие всем требованиям вакансии автоматически не оценивается. Перед запуском проверяйте резюме, подборку и текст письма.

## Установка

Готовые сборки содержат интерфейс и Python-движок. Пользователю не нужно отдельно устанавливать Python, Node.js или Rust.

1. Откройте **[страницу загрузки](https://github.com/DenisDudyrew/apply./releases)** и выберите версию. Вход в GitHub для скачивания не нужен.
2. В разделе **Assets** скачайте установщик:

   | Ваш компьютер | Файл |
   | --- | --- |
   | Windows x64 | `Apply-…-Windows-x64.exe` |
   | Mac с Apple Silicon | `Apply-…-macOS-Apple-Silicon.dmg` |
   | Mac с Intel | `Apply-…-macOS-Intel.dmg` |

3. На Windows запустите `.exe`; на Mac откройте DMG и перенесите Apply в «Программы».

Архивы **Source code** содержат исходники и не нужны для установки. Файл `SHA256SUMS.txt` содержит проверочные суммы установщиков.

Бета не имеет внешнего сертификата издателя: Windows-сборка не подписана сертификатом, macOS-сборка имеет ad-hoc подпись без нотарификации Apple. Система может предупредить при запуске. Автоматического обновления пока нет — новые установщики устанавливаются вручную.

## Первый запуск

1. Откройте Apply и войдите в hh.ru через кнопку аккаунта.
2. В настройках создайте профиль, загрузите свои резюме и выберите нужное.
3. Выберите рекомендации по резюме или поиск по ключевым фразам. При необходимости ограничьте названия вакансий.
4. Настройте письмо, максимум отправок и правила пропуска.
5. Сначала выполните поиск **без отправки** и проверьте подборку. Этот режим не отправляет отклики.
6. Запустите отклики. Приложение показывает прогресс и запросит ваше участие, если оно потребуется.

### Письма

В шаблоне доступны подстановки:

- `{vacancy}` — название вакансии;
- `{company}` — название компании;
- `{resume}` — название выбранного резюме.

В настройках можно посмотреть предварительный текст. Режим «не добавлять» не позволяет отправлять вакансии, где письмо обязательно: такие карточки пропускаются.

### Правила обработки

- **Без анкет:** пропуск обязательных вопросов и тестов. Если выключить, доступные ручные формы потребуют участия пользователя.
- **В своей стране:** сравнение страны вакансии со страной выбранного резюме. Неизвестная страна при включённой настройке требует проверки; при выключенной иностранная вакансия передаётся для ручного решения.
- **Спокойный темп:** паузы 30–60 секунд между карточками. Это не гарантирует отсутствие капчи. При выключении используется `pause_seconds` из конфигурации, не менее 3 секунд.

Максимум 1000 — настройка приложения, а не обещание отправить столько откликов или обход ограничений hh.ru. Лимит сервиса или отказ доступа может остановить запуск раньше.

## Капчи и ручные формы

Приложение не распознаёт капчи автоматически и не гарантирует исчезновение проверки после ожидания.

При API-капче доступны **две паузы по 10 минут** с безопасной проверкой через GET-запрос. Если проверка остаётся, потребуется ручной ввод. Кнопка **«Заполнить сейчас»** позволяет не ждать. Успешный GET сам по себе не считается решением капчи: исходная операция может снова получить явный отказ. При входе код и капча запрашиваются сразу, без этих пауз.

Капча показывается в панели. Для браузерной проверки доступны отправка ответа и запрос другой картинки; неверный ответ обновляет изображение штатным способом hh.ru.

Для доступных ручных анкет панель показывает изображение страницы hh.ru: можно нажимать поля и кнопки, вводить текст, прокручивать страницу и продолжать после заполнения. Браузер ручных форм скачивается при первом использовании. Обычные API-отклики не требуют Chromium. В ручной форме сайт может попросить дополнительный вход и проверку выбранного резюме.

## Очередь, остановка и повторы

Каждая пара «резюме + вакансия» учитывается в SQLite. Подтверждённые отправки и другие уже обработанные записи не повторяются автоматически.

Если ответ на отправку потерян, результат помечается как неопределённый. Автоматического повторения POST нет: сначала проверьте отклик на hh.ru. Записи со статусами `pending`, `uncertain`, `review` и `stopped` также не отправляются повторно автоматически.

Остановка срабатывает при ближайшей проверке; уже выполняющийся сетевой запрос может завершиться раньше. Закрытие desktop-окна останавливает движок и сохраняет очередь. После перезапуска можно продолжить необработанные карточки. Прерванная отправка без подтверждения остаётся для проверки.

В режиме локальной веб-панели закрытие вкладки само по себе не останавливает процесс. Одновременные отправки с одними данными защищены файловой блокировкой.

## Локальные данные

В установленном приложении данные находятся в пользовательской папке Apply:

- **macOS:** `~/Library/Application Support/Apply`;
- **Windows:** папка Apply внутри `%LOCALAPPDATA%`;
- токены desktop-входа — в **Keychain** или **Диспетчере учётных данных Windows**.

В папке данных сохраняются профили (`profiles.json`), очередь (`queue.sqlite3`), журнал (`state.sqlite3`), подборка, настройки и файлы ручного браузера. Журнал таймингов не сохраняет ответы на капчи.

У каждого пользователя собственная локальная сессия. В опубликованные исходники и установщики не включаются личные резюме, токены, история, снимки или браузерные профили разработчика. Для работы приложение обращается к hh.ru; при установке зависимостей или браузера также нужны их источники загрузки.

Локальный сервер слушает только `127.0.0.1`; действия защищены токеном панели и проверкой источника. Сервер отдаёт собранный интерфейс, а не папку проекта.

Кнопка отключения аккаунта удаляет локальные API-токены. Браузерная сессия ручных форм может оставаться активной; это не отзыв всех сессий аккаунта hh.ru. Не передавайте личную папку данных другим людям.

## Разработка из исходников

Стек: **React + TypeScript + Vite**, **FastAPI + Python**, **Tauri + Rust**, SQLite и SSE. Авторизация и API-отклики используют [hh-applicant-tool](https://github.com/s3rgeym/hh-applicant-tool); ручные страницы — Playwright.

Для разработки нужны Python 3.12+ и Node.js. Для desktop-сборки дополнительно нужен Rust и инструменты сборки целевой ОС. В CI используются Python 3.13 и Node.js 24.

```bash
git clone https://github.com/DenisDudyrew/apply. apply
cd apply
python -m venv .venv
```

Активируйте окружение:

```bash
# macOS
source .venv/bin/activate
```

```powershell
# Windows PowerShell
.venv\Scripts\Activate.ps1
```

Затем установите зависимости и запустите панель:

```bash
python -m pip install -r requirements.txt
npm ci --prefix frontend
npm run build --prefix frontend
python ui.py --no-open
```

Откройте локальный адрес из вывода запуска. В разработческом режиме личные данные сохраняются в папке проекта и исключены из публикации. Desktop-версия использует отдельную пользовательскую папку; автоматического переноса данных между режимами нет.

Для разработки интерфейса запустите `npm run dev --prefix frontend` и используйте `http://127.0.0.1:5173` вместе с Python-сервером. На macOS также сохранён запуск через `bash start.command`.

### Проверки

```bash
python -m unittest -q
python -m playwright install chromium
python tests/browser_smoke.py
```

Браузерный сценарий использует изолированные тестовые данные и не отправляет реальные отклики. Он проверяет вход и код, подборку, настройки профилей, капчу, ручные формы, остановку и историю.

### Сборка установщиков

Собирать нужно на целевой ОС. Помимо Rust потребуются инструменты сборки Tauri для Windows или macOS.

```bash
python -m pip install -r requirements-build.txt
npm ci --prefix frontend
npm run build --prefix frontend
python scripts/build_desktop.py
python scripts/test_frozen.py
```

Для публикации готовых проверенных установщиков запустите workflow **Publish installer release**: укажите ID успешной сборки `Desktop installers` и тег версии. Он проверит результат всех платформ, подготовит файлы с понятными названиями и SHA-256, создаст черновик релиза и опубликует его после проверки наличия всех установщиков. Релиз привязывается к исходному коммиту сборки. Повторная публикация существующего тега автоматически не перезаписывает файлы.

Готовые установщики находятся в `src-tauri/target/release/bundle/`. Проверка запускает автономный движок с чистым профилем; на macOS дополнительно проверяется движок внутри подписанного `.app`.

Для загрузки встроенных библиотек Python Mac-пакет использует исключение подписи `com.apple.security.cs.disable-library-validation`, заданное только для приложения в `src-tauri/Entitlements.plist`.

Публичные исходники подготавливаются через `python scripts/prepare_publication.py`: скрипт копирует разрешённые файлы в `.build/publish` и проверяет их на известные локальные данные аккаунта. Личные настройки `config.json` и `letter.txt` не публикуются; для новых пользователей предназначена папка `defaults/`.

## Ограничения и условия

- Мобильных приложений, автоматического расписания и автоматического обновления в этой итерации нет.
- Работодательские чаты после отклика не отслеживаются.
- Капчи, анкеты, ограничения доступа и изменения hh.ru могут потребовать вашего участия или обновления клиента.
- Используйте приложение с собственным аккаунтом и проверяйте результаты отправки.

Атрибуция и условия стороннего клиента приведены в [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md). Условия зависимости `hh-applicant-tool` включены без изменения; проект предназначен для бесплатного некоммерческого использования.
